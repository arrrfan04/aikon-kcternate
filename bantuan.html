Pusat Bantuan & Dukungan

Panduan penggunaan aplikasi AIKON, pertanyaan umum (FAQ), dan kontak kantor cabang.

Manual Book Penggunaan

1

Masukkan NPP & Password

Gunakan Nomor Pokok Pegawai (NPP) Anda yang telah didaftarkan oleh SDMUK beserta password yang sesuai.

2

Jika Lupa Password

Jika lupa password, gunakan opsi "Lupa password?" di layar masuk dan akan muncul notifikasi untuk menghubungi admin.

1

Ketik Pertanyaan di Beranda

Masukkan kata kunci atau pertanyaan seputar alur kerja, e.g. "SOP klaim bayi". Hasil pencarian akan muncul secara dinamis di dropdown.

2

Klik Hasil untuk Chat Box

Klik pada baris hasil pencarian untuk membuka asisten interaktif AIKON yang merangkum isi jawaban beserta tautan unduhan dokumen terkait.

1

Pilih Kategori Dokumen

Gunakan bilah select kategori atau ikon filter untuk memilah data SOP, Regulasi, DJP/Panduan Kerja, Formulir, atau FAQ.

2

Unduh Berkas Resmi

Tekan tombol "Unduh" untuk langsung mendapatkan file dokumen rujukan resmi yang tersimpan di Google Drive pusat.

1

Pelajari Modul Kerja Staf Baru

Buka menu Onboarding untuk mengakses modul belajar bertahap yang disesuaikan untuk proses adaptasi Anda di kantor cabang.

2

Tandai Selesai & Pantau Progres

Klik "Tandai Selesai" pada setiap modul yang telah dipelajari. Progres visual Anda akan langsung terupdate di dashboard analitik pribadi.

FAQ Sistem & Penggunaan

Bagaimana cara mendaftarkan akun pegawai baru?
Pendaftaran akun pegawai baru hanya dapat dilakukan oleh Administrator SDMUK Kantor Cabang melalui portal Dashboard Admin AIKON dengan menginputkan Nama, NPP, Divisi, dan password awal.
Mengapa dokumen tidak dapat diunduh?
Pastikan koneksi internet Anda stabil dan akun Google Anda memiliki hak akses untuk membuka link Google Drive yang terdaftar di spreadsheet. Hubungi admin jika link dokumen rusak.
Apakah data di dashboard terupdate real-time?
Ya, setiap kali admin mengunggah dokumen SOP/Regulasi baru atau pengguna menyelesaikan modul onboarding, dashboard analitik akan otomatis diperbarui.
Bagaimana jika ada kesalahan data pada modul Onboarding?
Modul onboarding dikelola secara terpusat oleh Bagian SDMUK. Jika menemukan ketidaksesuaian alur kerja pada modul, Anda dapat menyampaikan masukan ke humas cabang melalui nomor kontak tertera.
